
# Desafio Climb Stairs - EBAC

Projeto desenvolvido como atividade prática
do curso de Desenvolvimento Back-end Java da EBAC.

## Objetivo

Resolver o problema Climb Stairs utilizando
recursividade em Java.

O usuário pode subir uma escada com movimentos
de 1 ou 2 degraus. O programa calcula quantas
maneiras diferentes existem para chegar ao topo.

## Conceitos Utilizados

- Recursividade
- Casos base
- Relação de recorrência
- Estruturas condicionais
- Métodos em Java
- Testes de resultados

## Regra Matemática

F(n) = F(n-1) + F(n-2)

Casos base:
- F(1) = 1
- F(2) = 2

## Exemplos

- 2 degraus: 2 maneiras
- 3 degraus: 3 maneiras
- 4 degraus: 5 maneiras
- 5 degraus: 8 maneiras

## Estrutura

- src/ClimbStairs.java

## Como Executar

1. Abra o projeto no IntelliJ IDEA.
2. Acesse src/ClimbStairs.java.
3. Execute o método main().
4. Confira os resultados dos testes no console.
